
# Wild-type RBD docking

Docked structural ensemble for the **wild-type (reference) RBD** construct.

## Files

- **`cluster1_1.pdb` … `cluster5_4.pdb`** — Twenty PDB structures: five HADDOCK clusters with four models each.
- **`plots/`** — HTML interaction analysis charts (`irmsd_*`, `fcc_hs`, `elec_boxplot`, `vdw_boxplot`, etc.).
- **`Screenshot from 2025-03-15 *.png`** — Exported views from the docking analysis session (March 2025).

## Interpretation

Lower interface RMSD and favorable score distributions in the HTML plots indicate stable binding modes. Compare these models with [`../Master_sequence/`](../Master_sequence/) to evaluate whether the designed master sequence maintains similar interface quality.

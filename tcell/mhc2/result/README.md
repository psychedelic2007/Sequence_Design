
# MHC-II per-allele results

Per-allele **residue-level T-cell scores** for class II predictions, produced from [`../`](../) inputs via [`../../TCell_Calculation.py`](../../TCell_Calculation.py).

For design, prefer the aggregated [`../../mhc2_averaged_scores.csv`](../../mhc2_averaged_scores.csv) and [`../../combined_mhc_scores.csv`](../../combined_mhc_scores.csv).
